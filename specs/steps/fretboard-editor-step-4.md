# Step 4: Controls — toolbar de edição

**Feature:** fretboard-editor
**Covers AC:** AC-4 (limpar), AC-5 (tuning), AC-8 (start fret)

## Contract

- Botão "Limpar" remove todos os marcadores
- Select de afinação recalcula notas e reseta marcadores
- Input de casa inicial move a janela de casas visíveis
- Tipos de marcador: preenchido (default), aberto (○), X (abafado)
- Campo de texto para rótulo customizado (max 6 chars)

## Verification

- [x] Limpar remove todos os marcadores do canvas
- [x] Mudar afinação atualiza labels das cordas e notas
- [x] Casa inicial 5 mostra casas 5-16
- [x] Tipo ○ desenha círculo vazio
- [x] Tipo X desenha X sobre a corda
